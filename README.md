# 光跡對決 (`pg-lighttrace`)

Tron 式的光循環對決。你的光車永遠往前跑，身後留下不會消失的光牆；
撞到邊界、光柱或任何一道光牆（包含自己的）就出局。

類型：**光循環／留跡包圍** · 系列：街機

## 玩法

- **轉向就是全部的操作。** 方向鍵／WASD、螢幕下方的方向墊，或直接在場上滑一下。
  不能一百八十度掉頭，反向輸入會被忽略。轉向有兩格緩衝，手比車快也不會漏掉。
- **兩台車搶同一格＝雙亡。** 對撞誰都活不了。
- **模式**
  - **生存對決** — 三勝制。每回合最後活著的人拿下勝場，場地每回合輪換。
  - **佔格爭霸** — 限時搶地盤。先佔滿目標格數直接贏，時間到就比誰佔得多。
- **難度**（見習／標準／光刃）決定節拍速度與 AI 強度。光刃的 AI 會做地盤估算、
  貼牆省地、閃避對撞，並且主動壓縮你的可走空間。
- **對手數** 1～3 台，混戰時場面會很快被切碎。

最高分經 `/api/kv` 存在場域裡（每個 origin 各自一份）。

## 開發

純 HTML／CSS／JavaScript，無 build step。本機直接開 `index.html`，
或經 Playgrounds／go 安裝。

```bash
npx vitest run
```

`game.js` 是不碰 DOM 的純邏輯層（格子地圖、光跡、AI、回合與勝負），
`app.js` 只負責 canvas 繪製、輸入與畫面狀態。
